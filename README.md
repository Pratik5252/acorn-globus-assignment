## 🛠️ Local Setup

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd acorn_globus
   ```

2. **Install dependencies**
   ```bash
   pnpm install
   ```

3. **Run the development server**
   ```bash
   pnpm dev
   ```
